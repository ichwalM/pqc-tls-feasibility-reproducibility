# Data dictionary

The canonical run-level file is
`data/processed/all_runs_combined_FINAL.csv`.

| Column | Meaning |
|---|---|
| `timestamp` | Timestamp recorded by the measurement pipeline |
| `tier` | Legacy server label: `low`, `mid`, or `high` |
| `suite` | TLS key-exchange configuration: `classical` or `hybrid` |
| `concurrency` | Configured concurrent connection count |
| `network` | Configured network condition: `baseline`, `delay50`, `delay100`, or `loss1` |
| `run_id` | Unique identifier assigned to the run |
| `measurement_type` | `pure_handshake` or `end_to_end` |
| `latency_ms` | Recorded timing metric in milliseconds; its boundary depends on `measurement_type` |
| `latency_p95_ms` | Run-level 95th-percentile request latency for end-to-end workloads |
| `latency_p99_ms` | Run-level 99th-percentile request latency for end-to-end workloads |
| `cpu_pct` | Monitored-process CPU summary for an end-to-end run |
| `mem_mb` | Monitored-process resident-memory summary in MiB for an end-to-end run |
| `failures` | Failure count recorded by the pipeline for the run |
| `group_verified` | Whether the intended TLS group was reported as verified |
| `netem_status` | Status label recorded for the configured network condition |
| `notes` | Optional pipeline notes |

`aggregates_FINAL.csv` contains descriptive summaries grouped by server label,
TLS configuration, concurrency, network condition, measurement type, and
metric. Its `ci95_lo` and `ci95_hi` fields describe within-configuration mean
intervals. They are not the hybrid-minus-classical Welch difference intervals
generated by `scripts/analysis/paper_statistics.py`.
