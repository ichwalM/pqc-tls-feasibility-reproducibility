# Public-copy redactions

The following operational identifiers were replaced before preparing this
folder for public hosting:

- routable laboratory IP addresses;
- SSH account names;
- MAC addresses;
- virtual-machine UUIDs and generation identifiers; and
- the benchmark VM machine ID.

The replacements use explicit `REDACTED_*` markers or documentation-only
addresses from `192.0.2.0/24`. These changes do not affect experimental metrics,
conditions, TLS-group labels, timestamps, run identifiers, or statistical
values.

The hardware records still disclose processor, memory, storage, operating
system, and software-version information because these fields are relevant to
interpreting the experiment.
