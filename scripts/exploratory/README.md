# Exploratory scripts

`stats_tests_legacy.py` is retained to document an earlier exploratory analysis
path. It includes ANOVA and Tukey procedures that are not presented as the
statistical basis of every result in the final paper.

Use `../analysis/paper_statistics.py` for the reported hybrid-minus-classical
mean contrasts and nominal Welch confidence intervals. Use
`../analysis/verify_dataset.py` for structural validation of the archived data.
